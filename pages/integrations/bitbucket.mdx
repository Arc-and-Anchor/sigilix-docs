# Bitbucket

Bitbucket integration is **on the roadmap and not yet available**. There is no committed release date yet.

When it ships, the Bitbucket integration is planned to mirror the GitHub experience: install Sigilix as a Bitbucket App, listen for pull request events, post reviews as PR comments. The five specialists — four domain specialists (Metis, Argus, Iris, Eunomia), unified by Harmonia — would run unchanged.

If Bitbucket support is critical for your team, [get started](https://app.sigilix.ai/login) and tell us — we prioritize by demand.
