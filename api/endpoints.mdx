<Note>
The Sigilix API is in **private beta**. Endpoints, payload shapes, and rate limits may change without backward-compat guarantees until v1 GA.
</Note>

## Base URL

```
https://api.sigilix.ai/v1
```

All endpoints accept JSON and return JSON. Authentication via `Authorization: Bearer <PAT>` — see [Authentication](/api/authentication).

## Reviews

### List reviews

```http
GET /v1/reviews?owner=:owner&repo=:repo&pr=:number&limit=:n
```

Returns a paginated list of past reviews on a PR.

```json
{
  "reviews": [
    {
      "id": "rev_2y8tA9...",
      "owner": "Sigilix",
      "repo": "sigilix",
      "pr_number": 42,
      "head_sha": "a1b2c3d4",
      "verdict": "request_changes",
      "synthesized_at": "2026-05-05T03:14:00Z",
      "specialists_succeeded": ["logic", "security", "performance", "tests"],
      "findings_count": 4,
      "summary": "Zeus synthesized 4 findings across the domain specialists..."
    }
  ],
  "next_cursor": null
}
```

### Get a review

```http
GET /v1/reviews/:id
```

Returns the full review including all findings.

```json
{
  "id": "rev_2y8tA9...",
  "owner": "Sigilix",
  "repo": "sigilix",
  "pr_number": 42,
  "head_sha": "a1b2c3d4",
  "verdict": "request_changes",
  "summary": "...",
  "findings": [
    {
      "id": "fnd_4c2bX1...",
      "specialist": "security",
      "category": "security",
      "severity": "critical",
      "path": "src/api/checkout.ts",
      "line": 142,
      "headline": "missing CSRF verification on POST /checkout",
      "body": "...",
      "suggested_patch": null
    }
  ]
}
```

## Findings

### Fetch a finding

```http
GET /v1/findings/:id
```

Returns a single finding with its full context (provenance, source-line excerpt, suggested patch if applicable).

See [Webhooks](/api/webhooks) for the outbound events Sigilix can fire when a review completes.

## Errors

| Status | Meaning |
|---|---|
| 401 | Missing or invalid PAT |
| 403 | PAT lacks required scope |
| 404 | Resource not found |
| 429 | Rate limit exceeded |
| 500 | Internal error — retry with exponential backoff |

Error bodies follow the [JSON Problem Details](https://datatracker.ietf.org/doc/html/rfc7807) format:

```json
{
  "type": "https://docs.sigilix.ai/api/errors#unauthorized",
  "title": "Invalid PAT",
  "status": 401,
  "detail": "The provided personal access token does not exist or has been revoked."
}
```
