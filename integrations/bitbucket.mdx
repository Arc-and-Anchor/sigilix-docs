Bitbucket integration is **on the roadmap**. Estimated availability: **Q4 2026**.

The Bitbucket integration will mirror the GitHub experience: install Sigilix as a Bitbucket App, listen for pull request events, post reviews as PR comments. The five-agent ensemble runs unchanged.

If Bitbucket support is critical for your team, [register interest at sigilix.ai/signup](https://sigilix.ai/signup).
